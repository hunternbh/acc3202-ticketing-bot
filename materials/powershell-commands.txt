# Ticketing Exercise Commands

Replace `acc3202-ticketing-bot` with your Render app name.

Example:

```text
https://ticketing-exercise.onrender.com
```

Default values:

```text
SEED_SECRET: hunter-seed-2026-private
Admin email: admin@hunter-ticket.com
Admin password: adminpass
```

---

## Before Starting

- Event 1 has tickets priced at **$0**.
- Events 2–5 have tickets priced at **$1 each**.
- Change the user list in `index.js` before reseeding.
- The GitHub cron job pings the Render app every 5 minutes because the free Render server may sleep.

---

## 1. Reseed Database

```powershell
curl.exe -X POST "https://acc3202-ticketing-bot.onrender.com/api/admin/seed-database" `
  -H "x-seed-secret: hunter-seed-2026-private"
```

---

## 2. Login as Admin

```powershell
$response = Invoke-RestMethod `
   -Uri "https://acc3202-ticketing-bot.onrender.com/api/login" `
   -Method POST `
   -ContentType "application/json" `
   -Body '{"email":"admin@seatgate-ticket.com","password":"adminpass"}'

$token = $response.token
```

---

## 3. Release More Tickets

This releases 10 more tickets for `ticketTypeId = 5`.

```powershell
Invoke-RestMethod `
  -Uri "https://acc3202-ticketing-bot.onrender.com/api/admin/release-more" `
  -Method POST `
  -ContentType "application/json" `
  -Headers @{ Authorization = "Bearer $token" } `
  -Body '{"ticketTypeId":5,"additionalQuantity":10}'
```

---

## 4. Check Holdings

```powershell
Invoke-RestMethod `
  -Uri "https://acc3202-ticketing-bot.onrender.com/api/admin/holdings" `
  -Method GET `
  -Headers @{ Authorization = "Bearer $token" } |
Format-Table email, wallet_balance, event_title, ticket_type, quantity_owned, amount_spent -AutoSize
```

---

## 5. Public Check Tickets

This checks ticket availability for Event 2.

```powershell
Invoke-RestMethod `
  -Uri "https://acc3202-ticketing-bot.onrender.com/api/events/2/tickets" `
  -Method GET |
Select-Object -ExpandProperty tickets |
Format-List *
```
